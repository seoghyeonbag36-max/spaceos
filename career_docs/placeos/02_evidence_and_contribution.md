# PlaceOS 구현 근거와 지원자 기여 기록

내부 검토용. 채용 담당자에게 보내는 ZIP에는 포함하지 않는다. 조사 기준일은 2026-09-25이며, 원본 코드와 데이터는 수정하지 않았다. 저장소의 문서에 적힌 진행률과 성능을 현재 실적으로 전재하지 않는다.

## 판정 기준

| 상태 | 의미 |
|---|---|
| 구현 확인 | 해당 코드 경로를 읽고 기능의 존재와 처리 방식을 확인했다. 정상 실행 전체를 보장하지 않는다. |
| 실행 확인 | 이번 작업에서 명시한 로컬 입력과 명령으로 결과를 확인했다. 배포·실사용 효과와 다르다. |
| 기존 결과로만 확인 | 저장된 결과 파일이 있다. 이번 작업에서 원 실험을 재현하지 않았다. |
| 향후 제안 | 아직 수행하지 않은 적용·연구 계획이다. |
| 확인 불가 | 제공 자료만으로 판정할 수 없다. |

근거 ID의 파일 해시·함수명과 로컬 실행 결과는 `internal/repository_audit.json`에 보존한다. 자동 검사는 경로와 기호의 존재를 확인하며, 의미상의 주장 일치 여부는 본문과 소스를 대조해 검토한다.

## 지원자와 도구의 기여

사용자가 2026-09-25 대화에서 기획·개발을 맡았고, 총 소요 시간이 150시간 내외이며, 사업 방향성과 가치를 직접 만들었다고 밝혔다. 이는 **본인 진술**이다. 코드와 문서의 존재만으로 세부 작성자·업무시간을 독립 검증한 것은 아니다.

| 항목 | 현재 기록 | 근거 수준 | 보완 자료 |
|---|---|---|---|
| 프로젝트 역할 | 기획·개발 | 본인 진술 | 담당 기능 목록, 설명 가능한 코드·설계 사례 |
| 사업 방향과 가치 제안 | 지원자가 수립 | 본인 진술 | 최초 기획안·수정 이유·의사결정 기록 |
| 총 투입 시간 | 약 150시간 | 본인 추정, 시간기록 대조 없음 | 기간별 활동기록. 정밀 생산성 계산에 사용 금지 |
| 참여 기간 | [작성 필요] | 확인 불가 | 시작·종료 시점 또는 진행 중 여부 |
| 직접 작성·수정 코드 | [작성 필요] | 확인 불가 | 파일·커밋·변경 설명. 커밋 작성자만으로 단독 기여 판단 금지 |
| 팀 규모·협업 | [작성 필요] | 확인 불가 | 공동 작업자 역할과 본인 책임 구분 |
| 기존 AI 도구 활용 | [작성 필요] | 구체 사용 범위 확인 불가 | 어떤 도구가 무엇을 생성했고 본인이 무엇을 검토했는지 |
| 이번 Codex 작업 | 저장소 조사, 선택 검증, 지원·연구 문서 초안, PDF·ZIP 생성 | 이번 실행 기록 | 지원자 과거 수행 실적이나 추가 개발 시간에 합산하지 않음 |

## 기획 결정 사례의 안전한 구성

확인된 큰 결정은 '공간·상권 데이터를 창업 의사결정 지원으로 연결하는 사업 방향과 가치 제안을 수립했다'는 본인 진술이다. 다음 세부 사항은 면접 전에 지원자가 채운다.

- 처음 해결하려던 사용자 문제: [작성 필요]
- 검토했던 대안과 선택 이유: [작성 필요]
- 지원자가 직접 확정한 범위와 포기한 범위: [작성 필요]
- 해당 결정을 보여주는 기획안·커밋·회의 기록: [작성 필요]
- 결정 뒤 확인한 변화: [작성 필요]. 측정하지 않았다면 '효과 미측정'으로 유지.

지번 중복 제거, 감성 null 유지, KPI 기준 수정은 저장소에서 확인한 **프로젝트의 처리 방식**이다. 지원자가 자신이 결정했다고 확인하기 전에는 '내가 설계했다'로 쓰지 않는다.

## 사용하지 않는 주장

고객 확보, 유료 매출, 투자 유치, 특허·기술이전 계약, 정확한 공실 예측, 추천에 따른 매출 증대, 업무시간 절감률, 독립적인 현장 검증, 논문 게재·수상, 모든 코드의 단독 작성은 확인 불가다. 이번 생성 문서는 채용 서류 작성 지원 결과이며 학술 실적으로 간주하지 않는다.

## 채용 출처 추가 확인

직무와 조건은 `01_job_fit_analysis.md`의 J01~J05에 분리했다. J01은 사용자 첨부 이미지, J02·J03은 연세대 공식 공고, J04는 AI 사용 금지 공지, J05는 앵커사업단 공식 HWP다. 개인 경력의 근거로 쓰지 않는다. HWP는 내려받아 텍스트 레코드에서 문항과 분량을 확인했으며 서식의 예시 개인정보는 산출물에 복사하지 않았다. 원본·웹 페이지는 `.build/`에만 보관하며 Git과 배포 ZIP에서 제외한다.
