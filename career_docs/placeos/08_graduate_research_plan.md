# PlaceOS 석사 연구 준비 계획

채용 제출물과 분리한 개인 연구 준비 자료 · 2026-09-25

## 우선 연구 제안

**공간 기반 창업 의사결정 지원 데이터의 계산 재현성과 정보 품질 평가**를 우선 추천한다. 핵심은 공실을 잘 예측한다고 주장하는 것이 아니라, 동일 자료를 결합·집계하는 과정이 얼마나 일관되며 어떤 조건에서 비교가 어려운지 검증하는 것이다. 현재 확보한 Gold 자료와 서비스 코드를 사용할 수 있고, 독립적인 현장 공실 정답이나 신규 사용자 실험 없이도 제한된 계산 검증부터 시작할 수 있다.

이 주제는 기술경영 관점의 데이터 기반 의사결정 지원 연구 준비안이다. 실제 판단 개선 효과를 아직 측정하지 않으므로 서비스 효과 연구가 완성됐다고 보지 않는다. AI 모델 개발을 필수로 삼는 학과·연구실에는 주제 적합성을 별도로 확인해야 한다. 학술적 기여와 석사논문 적정 범위는 지도교수와 논의한다.

## 기술경영과 AI 방향 비교

| 방향 | 가능한 질문 | 현재 자료와 검증 제약 | 우선순위 |
|---|---|---|---|
| 기술경영의 판단 효과 | 출처·불확실성 설명이 판단 정확성·일관성·시간에 영향을 주는가 | 판단 기준과 동의받은 참여자가 필요하다. 현재 사용자 실험 없음 | 계산 품질 연구 이후 별도 확장 |
| 기술경영의 서비스 활용 | 창업지원 서비스가 실제로 활용되고 성과에 기여하는가 | 이용 로그·고객 결과·비교 조건이 필요하다. 제품 코드만으로 판정 불가 | 후순위 |
| 기술경영의 정보 품질 | 같은 입력의 집계가 재현되고 비교 가능한가 | 현재 가공 자료·코드와 과거 감사 산출물이 있음 | 우선 제안 |
| AI 공간·시계열 예측 | 다른 지역·시점에서 단순 기준보다 잘 예측하는가 | 분기 테이블은 있으나 현재 목표는 공실 대리변수다. 실제 공실 정답 부족 | 조건부 대안 |
| AI 텍스트 결합 | 리뷰가 정형자료 이상의 신호를 주는가 | 공간 귀속과 관측시점, 독립 목표변수가 부족하다. 현재 감성 기각 유지 | 자료 확보 전 보류 |
| AI 설명 가능한 추천 | 설명이 충실하며 새로운 지역에 일반화되는가 | 기존 업종 라벨과 최적 업종을 구분해야 한다. 설명·판단 평가 기준 필요 | 범위 재설계 후 검토 |

## 실제 자료와 연구 단위

이번 로컬 확인 대상은 ACTIVE_HUBS의 81개 거점이다. 공실 관련 Gold 집계와 서비스 계산을 확인했고, 시계열 테이블은 81개 거점·22개 분기·1,782행이다. 분기 범위는 2021년 1분기부터 2026년 2분기이며 거점·분기 키 중복은 없다. R-ONE 관련 세 열에는 각각 18개 결측이 있다. 이 수치는 직접 파일을 읽은 집계이고, 자료의 실제 관측 정확도나 모든 자료의 동일 시점을 보증하지 않는다.

우선 연구의 관측 단위는 '거점 × 고정 데이터 버전 × 계산 조건'이다. 셀은 거점 안의 하위 단위이며 반복 변형을 독립 표본으로 세지 않는다. 과거 감사 파일의 표본과 현재 거점 범위를 섞지 않는다. 원자료 이용권한과 관측시점이 확인되지 않는 항목은 제외하거나 미평가로 남긴다.

## 연구 질문과 비교 기준

RQ1. 동일 Gold 입력과 코드 버전에서 계산 결과가 재현되는가.

RQ2. 내용은 같고 객체 순서만 다른 입력에서 전체 집계와 셀별 값이 유지되는가.

RQ3. 공간 키·결측·자료 버전 차이를 기록하면 어느 지표가 평가 가능하며 무엇을 미평가로 남겨야 하는가.

예측모형을 훈련하는 연구가 아니므로 기준모형 대신 **현재 서비스 계산을 기준 구현**으로 고정한다. 별도 계산 코드로 셀 합을 검산하고, 정렬·역순·고정 난수 순열 등 사전 지정 변형과 비교한다. 순서 변경은 복사본에서만 수행하며 제품 집계·출처 규칙을 바꾸지 않는다. 과거 순서 민감도 결과를 이미 알고 있으므로 새 분석도 탐색·재확인 연구라는 사실을 공개한다.

## 평가와 판정

| 평가 | 측정 정의 | 해석 |
|---|---|---|
| 재현 일치 | 같은 입력 해시·코드에서 의미 출력의 일치 여부 | 바이트 해시와 내용 일치를 구분. 생성시각 등 제외 필드 사전 지정 |
| 전체 합 보존 | 적격 지번의 분모·영업 수와 셀별 합 대조 | 현실 정확도와 다른 계산적 성질 |
| 순서 민감도 | 조건별 공통 셀의 절대 차이, 셀 진입·이탈, 영향 거점 수 | 작은 반례도 보고. 임의 유의확률로 포장하지 않음 |
| 품질 판정 가능성 | 규칙별 통과·실패·미평가 수와 각각의 적용 분모 | 미평가를 통과·오류로 임의 전환하지 않음 |
| 시간 재현성 | 관측일·입수일·가공일·버전의 확인 가능 여부 | 현재 파일의 존재만으로 과거 시점 복원 가능 선언 금지 |

이번 문서 작업에서는 셀 합계 검산과 선택 테스트만 실행했다. 위 순서 변형과 독립 연구 평가 전체는 **미실행**이다. 과거 결과 파일은 선행 내부 자료로만 취급한다. 예측 성능표·사용자 효과 수치·통계적 유의성은 만들지 않는다.

## 누수와 사후 선택 방지

입력 파일 해시와 분석 규칙을 결과 보기 전에 고정하고, 기존 결과를 본 조건과 새 확인 조건을 구분한다. 같은 지번·건물 또는 반복 분기가 분할 양쪽에 섞이지 않도록 한다. 반복 변형으로 표본 수를 부풀리지 않으며 보유 범위 밖의 상권·기간에 일반화하지 않는다.

AI 예측으로 확장할 경우 지속성 예측과 단순 선형모형부터 비교한다. 업종은 학습 범위의 빈도 기준을 먼저 둔다. 전처리·결측 대체·변수 선택은 학습 자료에서만 적합하고, 시간 순서 학습·검증·최종 평가를 분리한다. 인접 지역·공유 원천 통계는 같은 묶음으로 관리한다. MAE·기준모형 대비 차이와 거점 단위 불확실성을 보고하며, 실제 공실 정답이 없으면 목표 이름도 '공실 대리변수'로 유지한다. 예측 차이를 개입의 인과효과로 해석하지 않는다.

## 직장 병행을 고려한 범위

다음 일정은 입학·지도 가능성·복무 기준을 확인한 뒤 조정할 개인 준비안이며 학위 이수 일정 보장이 아니다. 대규모 크롤링, 새로운 LLM 평가, 사용자 실험을 동시에 포함하지 않는다.

| 준비 구간 | 작업 | 완료 기준 |
|---|---|---|
| 1~2주 | 연구 질문·문헌·파일 접근 범위 정리 | 계산 재현성과 현실 정확도를 구분한 프로토콜 |
| 3~4주 | 입력 버전·변수·공간 키·시점 기록 | 고정 인벤토리와 결측·미평가 표 |
| 5~8주 | 기준 계산과 사전 지정 변형 비교 | 실패·반례를 포함한 재현 로그 |
| 9~10주 | 다른 거점·버전 확인 가능성 점검 | 일반화 가능한 범위와 불가능한 범위 명시 |
| 11~12주 | 기술경영 관점의 해석과 연구계획 개정 | 방법·결과·한계가 구분된 검토 원고 |

추가 학습은 Python·SQL 자료 점검, 공간 데이터 좌표·결합·집계, 통계적 추론과 측정오차, 재현 가능한 실험 기록을 우선한다. AI 방향 선택 시 시계열 검증과 그래프 학습을 추가한다. 현재 개인 숙련도와 이수 과목은 [작성 필요]다.

## 추가 자료와 확장 조건

현실 공실 정확도를 평가하려면 공간 식별자와 관측시점이 맞는 독립 현장·임대관리 정답이 필요하다. 판단 효과 연구에는 독립 정답 또는 사전 확정된 채점 기준, 참여자 모집과 동의, 기관의 심의 필요 여부 확인이 필요하다. 서비스 활용 효과에는 실제 이용과 결과 자료, 선택 편향을 다룰 비교 설계가 필요하다. 이번 작업에서 참여자를 모집하거나 기관 자료에 접근하지 않았다.

## 진학 가능성과 근무 조건의 분리

고려대학교 기술경영전문대학원 공식 교육과정은 석사학위와 논문 또는 연구보고서 경로를 안내한다. 공식 시간표에는 평일 저녁과 토요일 과목이 보이지만, 향후 입학 학기의 운영과 직장 병행 허용을 보장하지 않는다. 학과의 최신 모집요강·졸업요건·수업시간과 채용기관의 복무 기준을 각각 확인해야 한다. [석사 교육과정](https://mot.korea.ac.kr/sub4_1_a_1.php), [시간표](https://mot.korea.ac.kr/sub5_1.php) (확인일 2026-09-25).

고려대 행정팀 공고의 평일 10:30~19:00, 토요일 08:50~16:10 근무는 위 저녁·토요일 수업과 충돌할 수 있다. 대체휴무가 수업 참석 허가를 의미하지 않는다. 연세대 앵커사업단은 09:00~18:00, 산학협력단은 09:00~17:20이며 통학시간과 실제 복무 규정을 함께 확인해야 한다. 어느 직장도 파트타임 학업 병행이 확정된 선택지로 분류하지 않는다.

AI 분야 과정은 [작성 필요: 정확한 대학원·학과·과정]. 'AI 대학원'이라는 표현만으로 파트타임 입학 가능성을 판단하지 않는다. 입학, 지도교수 배정, 학비 지원, 연구 참여, 근무시간 조정은 모두 미확인이다. 지원자는 채용 자기소개서의 주된 동기를 학업 편의로 구성하지 않는다.

## 선행 읽기와 확인 수준

Alsudais의 *Incorrect Data in the Widely Used Inside Airbnb Dataset*은 공개 자료의 수집 오류와 릴리스 간 재현성 문제를 다룬다. 저자 공개본의 서지·초록을 확인했으며, 그 결과를 PlaceOS의 오류율로 전용하지 않는다. PlaceOS에는 공간 객체 결합과 지번·셀 집계라는 별도 검증이 필요하다. [저자 공개본](https://arxiv.org/abs/2007.03019), [관련 출판 DOI](https://doi.org/10.1016/j.dss.2020.113453).

Roberts 등의 *Cross-validation strategies for data with temporal, spatial, hierarchical, or phylogenetic structure*는 의존성을 가진 자료의 평가 분할을 검토하는 방법론 문헌이다. AI 확장 시 공간·시간 분할을 설계하는 참고자료이며 PlaceOS 성능의 증거가 아니다. 출판사 페이지를 확인했으며 전체 실험 재현은 하지 않았다. [출판사 DOI](https://doi.org/10.1111/ecog.02881).

문헌은 연구 설계의 출발점이며 체계적 문헌검토 완료를 뜻하지 않는다. 기존 저장소 연구 초안도 학술 게재 실적이나 독립 검증으로 표시하지 않는다.
