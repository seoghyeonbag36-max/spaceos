임대시세는 격자 색이 아니라 금액이다

종전에는 100m 격자를 초록 5단계로 칠했다. “진한 곳이 비싸다”는 보였지만 얼마인지는 화면 어디에도 없었고, R-ONE 임대료는 상권 단위 값 하나라 셀마다 달라 보이던 차이도 공간 구조가 아니었다. 값이 실제로 갈리는 축은 층과 면적이라 그 축으로 내려갔다.

월 임대료(만원) = R-ONE 소규모상가 임대료(천원/㎡·월) × 층 계수 × 그 층 대장 면적(㎡) ÷ 10

R-ONE 2026년 2분기 가로수길 74.64천원/㎡·월 기준. 층 계수는 실측이 아니라 계수이며 Posting 의 임대료와 같은 표를 쓴다(두 화면이 같은 자리에 다른 금액을 내지 않는다). 호가·실거래가가 아니고 보증금·권리금·관리비가 빠져 있다. 한 층에 호실이 여럿이면 그 층 전체 금액이다.

상태

  • 자리 0곳 — 계산 버튼 비활성, 자리 선택 비활성
  • 계산 실패 — “계산에 실패했습니다” + 원문(진단용)
  • 코파일럿 설정됐는데 실패 — 경고 상자 + 아래는 폴백 계산이라고 명시
  • 응답의 자리·상권이 요청과 다르면 결과를 버린다

하지 않는 것

  • 층 단위 매물(Page 임대시세)을 ROI 표본으로 쓰지 않는다 — 여기 자리는 건물 단위 유닛이다
  • 이름·좌표로 인계 건물을 추측해 매칭하지 않는다
  • 권리금 0 전제를 실측처럼 보이게 하지 않는다

#영역내용데이터동작
1결론 머리결론 1줄 + 근거 3줄(무엇을 읽고 냈나 / 어떤 채널로 / 믿을 만한가). 스텁·HA 폐기 사실은 상세를 접어도 결론에 남는다생성 결과—
2지도 안내 줄 신규지도에 찍힌 것이 무엇인지: 행사 N곳과 출처(실데이터 / 미적재라 예시 / 못 불러옴), 가게 후보 칩 뜻events 응답—
3가게 프로필가게명(+검색) · 카테고리 · 거점(상권 컨텍스트, 선택) · 리뷰 · 접힘(주소·사진 URL·메뉴·키워드). 칸마다 「입력 규칙」 접힘. 모드: 공개 데모 / 상용 온보딩(조직 API 키 + 동의 4개, 접지 않음)GET /marketing/placesGET /marketing/reviews검색 후보를 고르면 기본정보·블로그 스니펫 채움. 자동 선택하지 않는다
4결과채널별 초안(온라인/오프라인 목록 → 편집·미리보기 → 원본 되돌리기·본문 복사) · 생성 원본 근거 · HA 검증 접힘(폐기/경고/통과, LLM 자체점검은 따로)POST /marketing/generatePOST /marketing/onboarding/generate생성 중 경과 초 표시(사진 포함 10~20초)
5지도 · 오프라인 홍보 장소 신규상권의 공공 문화행사 칩(행사명 · 날짜). 실데이터가 아니면 점선 + “예시”. LLM 을 부르지 않는 경로로만 받는다GET /marketing/events?district_id=(지도가 있을 때만)—
6지도 · 가게 후보·이 가게 신규상호 검색 결과를 검은 칩으로. 같은 상호가 여러 곳이면 위치로 고른다. 고른 가게는 “이 가게” 채움 칩으로 남는다places 응답의 좌표후보 칩 클릭 = 목록에서 고른 것과 같다. 카메라는 후보들 → 고른 가게 → 상권 중심 순

상태

  • 결과 전 — “왼쪽에 가게 프로필을 넣고 생성을 누르면…” 안내
  • 생성 실패 — 백엔드 기동 명령과 원문
  • LLM 을 못 탐 / HA 에 걸려 폐기 — 두 이유를 다른 문구로
  • 입력·모드를 바꾸면 이전 결과·초안·스니펫을 버린다

하지 않는 것

  • 지도 상권을 생성 요청의 컨텍스트로 몰래 넣지 않는다 — 폼에서 고른 거점만 쓴다
  • 상용 경로에 공개 검색 스니펫을 섞지 않는다
  • 편집한 초안을 HA 검증을 거친 것처럼 보이게 하지 않는다

표시 원칙 — 네 화면 공통

추정을 실측처럼, 없는 값을 0 처럼 보이게 하지 않는 것이 이 제품의 제1원칙이다. 화면 모양으로 그 차이를 말한다.

상황화면이 하는 것예
추정 · 확정이 섞일 때점선 테두리, 흐린 글자, “추정” 라벨probable 빈 층 · 추천 없는 자리 · 시드 행사
값이 없을 때0 이나 이웃 값으로 채우지 않고 없다고 적는다“이 거점에는 R-ONE 임대료가 없다” · “대표값 미제공”
빌려 온 값출처 라벨을 가른다rone 과 rone-shared(인접 상권 표본)
계수·근사단위를 숨기지 않고 식을 함께 싣는다층 계수 · vac_proxy → % 환산은 근사
접힌 상세요약줄에 안에 든 개수를 적고, 출처 줄은 접지 않는다「정체성 원자료 — 업종 N곳 / N군 …」
금액제외 항목을 같이 적는다“보증금·권리금·관리비 제외 · 호가가 아닌 추정”
