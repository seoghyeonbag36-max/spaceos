## 0. 이 문서가 확정하지 않는 것 — 가용성

**아래 어느 도메인도 "비어 있다"고 확인하지 않았다.** 웹 검색으로 본 것은
*기존 서비스·상표의 존재*이지 등록 가능 여부가 아니다. 등록 가능 여부는
**반드시 등록기관에서 직접 조회**해야 한다.

| 확인할 것 | 어디서 |
|---|---|
| `.kr` · `.co.kr` 등록 여부·등록 자격 | [후이즈검색(KISA)](https://xn--c79as89aj0e29b77z.kr/) · 가비아 · 후이즈 |
| `.com` · `.ai` · `.io` 등록 여부 | 등록기관 WHOIS (가비아·Cloudflare Registrar 등) |
| 국내 상표 선등록 | [KIPRIS](https://www.kipris.or.kr) — 제9류(소프트웨어)·제42류(SaaS)·제35·36류(부동산·광고) |
| 해외 상표 | USPTO TESS · EUIPO eSearch |

도메인이 비어 있어도 **동일 업종에 상표가 등록돼 있으면 쓸 수 없다.** 둘은 별개 절차다.
확인 전에는 이 문서의 어떤 이름도 다른 문서·발표자료에 "우리 주소"로 적지 않는다.

## 1. 후보 8개

브랜드명 `SpaceOS` 를 지키는 4개(A군)와, 선점·상표 충돌 시로 넘어갈 대체 4개(B군).

| # | 후보 | 군 | 왜 이 이름인가 (한 줄) |
|---|---|---|---|
| 1 | **spaceos.kr** | A | 브랜드를 그대로 두고 국가코드로 "한국 시장 서비스"를 못 박는다 — 1순위 |
| 2 | **spaceos.co.kr** | A | `.kr` 이 막혔을 때. 국내 B2B 에서 `.co.kr` 은 법인 신호가 강해 지자체·자산운용사 상대로 손해가 없다 |
| 3 | **spaceos.com** | A | 18~24개월 뒤 M&A·투자 노출을 볼 때 유일하게 국제 통용. 다만 **동명 선점 위험이 가장 높다**(§3) |
| 4 | **spaceos.ai** | A | 한국 `.kr` 계열이 다 막혔을 때의 브랜드 유지책. AI 엔진(LSTM·GNN)이 제품 핵심이라 의미가 어긋나지 않는다 |
| 5 | **twinmap.kr** | B | 디지털 트윈 + 지도. 우리가 실제로 보여주는 화면(지도 위 공실)을 그대로 부른다 |
| 6 | **streetos.kr** | B | `OS` 어법을 유지하면서 대상을 건물이 아니라 **골목 상권**으로 좁힌다 — 기존 빌딩 OS 들과 갈라지는 지점 |
| 7 | **gongsil.kr** | B | 공실(空室). 국내 고객이 검색·기억하는 단어 그 자체. 로마자 표기가 흔들리지 않는 드문 한국어 |
| 8 | **spacetwin.co.kr** | B | `SpaceOS` 를 못 쓸 때 의미를 가장 적게 잃는 이름 — 공간의 쌍둥이 |

**하이픈은 넣지 않는다.** `spaceos-twin.web.app` 이 임시로 보이는 이유의 절반은
하이픈이다. `space-os.kr` 류는 지금 문제를 그대로 옮겨온다.
`try-` · `get-` · `use-` 접두도 같은 이유로 뺐다(스타트업 랜딩 관용구라 B2B 에서 가볍다).

## 2. 전화로 불러줄 수 있는가

판정 기준은 하나 — **"제 메일은 ○○○@□□□ 입니다"를 상대가 되묻지 않고 받아적는가.**

| 후보 | 전화 난이도 | 실제로 벌어지는 일 |
|---|---|---|
| spaceos.kr / .co.kr / .com / .ai | **중** | "스페이스오에스"를 붙여 읽으면 **"스페이서스"로 뭉개진다**. `space` + `OS(운영체제)` 로 끊어 읽으면 즉시 복구된다. 상대가 OS 를 아는 B2B 담당자라 실패율은 낮다 |
| twinmap.kr | **쉬움** | twin·map 둘 다 초등 수준 영단어. 되묻는 일이 거의 없다 |
| streetos.kr | **중** | street 의 이중 `e` 를 한 번 확인받게 된다. 그 뒤는 spaceos 와 같다 |
| gongsil.kr | **쉬움(국내) / 불가(해외)** | 한국인 상대로는 최고 — 철자를 물어보지 않는다. 외국인에겐 의미도 철자도 0점 |
| spacetwin.co.kr | **쉬움** | 다만 `.co.kr` 이 붙어 입에서 길어진다("스페이스트윈 점 씨오 점 케이알") |

부수 기준 두 개:
- **이메일 길이** — `@spaceos.kr` (11자) 이 가장 짧다. 명함·서명에 유리하다.
- **한글 도메인**(`스페이스오에스.kr`)은 후보에서 뺐다. 전화로는 최상이지만 이메일 주소로 쓰면
  일부 메일 클라이언트에서 깨지고, B2B 명함에서 오히려 비표준으로 보인다.

## 3. 충돌 — 확인된 것

⚠ 아래는 **웹 검색으로 존재를 확인한 기존 서비스**다. 상표 등록 여부는 별도로 KIPRIS·USPTO 확인이 필요하다.

| 후보 | 충돌 | 성격 |
|---|---|---|
| **spaceos.*** (1~4) | **spaceOS** ([spaceos.io](https://spaceos.io/)) — 워크플레이스 경험 플랫폼, 2017 설립, 2023 년 **Equiem 에 인수**. 누적 $13.6M | 🔴 **가장 큰 위험.** 이름이 같은 데 더해 **업종이 인접**하다(빌딩·부동산 SaaS). 국내 상표만 비어 있어도 글로벌 확장·M&A 실사에서 반드시 걸린다 |
| **spaceos.*** (1~4) | Firebase 사이트 ID `spaceos` 는 **이미 다른 프로젝트가 선점**했다 (`firebase.json` 주석) | 🟡 도메인과 무관하지만, 이 이름이 붐빈다는 직접 증거 |
| **spaceos.*** (1~4) | 국내 "스페이스" 접두 서비스 포화 — 스페이스클라우드 등 공간대여 브랜드가 먼저 연상된다 | 🟡 국내 청취자가 "공간 대여 서비스"로 오해할 여지 |
| ~~placeos~~ | **PlaceOS** ([placeos.com](https://www.placeos.com/)) — 시드니, 스마트빌딩 OS | 🔴 **후보에서 제외했다.** 이름·업종이 정면 충돌한다 |
| **spacetwin.co.kr** (8) | **Spacetwin Systems** ([spacetwin.space](https://www.spacetwin.space/)) — 텍사스, 자체 크립토 토큰(STAR) 기반 | 🟡 업종이 다르고 규모가 작다. 다만 **크립토 연상**이 B2B 미팅에서 불리하게 붙을 수 있다 |
| ~~hubos~~ | **Hub OS** — 호텔 운영 자동화 | 🟡 후보에서 뺐다 |
| **twinmap.kr** (5) | 동명 서비스는 못 찾았다. 다만 국내 부동산에 **"-맵" 접미가 포화** — 밸류맵·플러스맵·코리아비즈맵 | 🟡 상표 **식별력이 약하다**(등록도, 방어도 어렵다) |
| **streetos.kr** (6) | 검색상 동명 서비스 없음 | 🟢 현재로선 가장 깨끗하다. 그래도 KIPRIS 확인 필요 |
| **gongsil.kr** (7) | 일반명사라 상표 등록 자체가 어렵다(식별력 없음). 남이 못 막는 대신 **우리도 못 막는다** | 🟡 + 브랜드가 "빈 곳"이라는 부정 프레임으로 고정된다 |

## 4. 권고 순서

1. `spaceos.kr` → 2. `spaceos.co.kr` → 3. `streetos.kr` → 4. `twinmap.kr`

`spaceos.com` 은 **spaceos.io 와 같은 프롭테크 업종**이라 값이 싸도 뒤로 미룬다.
1·2 를 잡더라도 국내 상표(제9·42류)를 함께 출원해 두는 편이 낫다 — 도메인만으로는
동명 해외 브랜드를 막지 못한다.
