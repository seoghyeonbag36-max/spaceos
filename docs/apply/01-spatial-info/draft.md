## 3. 활용한 공간정보·데이터 <!-- 배점: 데이터 확보 용이성 20 — 최고 배점 -->

데이터 확보 용이성을 "우리가 접근 권한을 가졌는가"로 읽으면 대부분의 출품작이 같은 답을
낸다. 이 서비스는 그 질문을 **"제3자가 같은 경로로 같은 자료를 다시 확보할 수 있는가"**로
바꿔 답한다. 서울 66거점의 건축물대장 기반 산출물은 전량 공개된 공공 API 에서 나왔고,
수집기와 실행 명령이 저장소에 그대로 있다.

| 데이터 | 출처기관 | 받는 것 | 수집기 |
|---|---|---|---|
| **GIS건물통합정보** | **국토교통부 브이월드** | 건물 footprint 폴리곤 · PNU · 층수 · 연면적 · 높이 · 용도코드 | `data/collectors/vworld_bldg.py` |
| 건축물대장 (전유부·층별개요) | 국토교통부 건축HUB | 층별 전유부 구성 · 용도 · 면적 | `data/collectors/building_vacancy.py` · `floor_capacity.py` |
| 상가(상권)정보 | 소상공인시장진흥공단 | 영업 중 점포의 위치·업종·층 | `data/collectors/building_vacancy.py` |
| 지방행정 인허가 | 행정안전부 LOCALDATA | 개·폐업 이력 | `data/collectors/localdata.py` |
| 상업용부동산 임대동향 | 한국부동산원 R-ONE | 공실률·임대료 분기 시계열 (대조 앵커) | `data/collectors/rone_rent.py` |
| 상권분석서비스 · 생활인구 | 서울 열린데이터광장 | 상권 분기 시계열 · 집계구 단위 유동 | `data/collectors/seoul_trdar.py` · `living_population_jipgyegu.py` |
| 지도 · 거리뷰 | 네이버 클라우드 플랫폼 | 베이스맵 · 파노라마 | `apps/frontend/src/lib/naverMap.ts` |

전 항목이 공개 API 이며, 민간 소스도 크롤링이 아니라 공식 API 로만 받는다. 접근 방식이
저장소에 고정돼 있다는 것은 곧 **확보 경로가 절차로 서 있다**는 뜻이다 — 건축HUB 는 일일
쿼터가 있어 하루 단위로 끊어 돌리며, 그 프리플라이트가 `scripts/quota_preflight.py` 로
문서화돼 있다. 필요한 키 목록은 `scripts/check_api_keys.py` 가 출력하고, 거점별 수집
진행 상태는 `scripts/chain_status.py --all` 로 확인한다. 제3자 재현에 필요한 것은 이 셋뿐이다.

## 8. 국가공간정보(브이월드) 활용 <!-- 주최 플랫폼을 실제로 쓰고 있다 -->

브이월드는 이 서비스에서 **참고 자료가 아니라 기반 레이어**다. 화면에 보이는 건물 하나하나가
브이월드에서 시작한다.

**무엇을 받는가.** 거점 코어 축의 bbox 로 GIS건물통합정보를 WFS(`getBldgisSpceWFS` ·
레이어 `dt_d010`)로 호출해 건물 footprint 폴리곤을 받는다. 함께 오는 것이 PNU · 층수 ·
연면적 · 높이 · 용도코드다. 서버의 반환 상한에 걸리면 bbox 를 4분할해 재귀적으로 타일링하고
PNU 와 fid 로 중복을 제거한다. 원본 XML 은 가공하지 않고 그대로 보관하며(Bronze 원칙),
파싱한 GeoJSON 을 병행 저장한다.

**무엇과 잇는가.** 브이월드가 주는 PNU 19자리를 시군구·법정동·산여부·본번·부번으로 분해해
**건축물대장과 조인한다.** 이 조인이 이 서비스의 척추다 — 브이월드가 건물의 *윤곽과 좌표*를
주고, 대장이 그 안의 *층별 구성*을 주며, 상가정보와 인허가가 *지금 영업 중인 칸*을 준다.
셋이 PNU 한 키로 붙기 때문에 "이 건물 3층이 비어 있다"는 문장이 성립한다.

**무엇이 되는가.** 그 결과가 서울 66거점의 건축물대장 기반 층별 공실 산출물이고, 공실
히트맵과 층 스택 화면이 그 위에 선다. 브이월드 수집기는 시험 스크립트가 아니라 서빙
파이프라인(`data/pipelines/build_page_master.py`)과 거점 온보딩 체인에 들어 있어, 거점을
하나 늘릴 때마다 같은 경로로 다시 돈다.

**재현.** `VWORLD_API_KEY` 는 브이월드에서 즉시 발급된다. 실호출 검증은 2026-07-08 에
마쳤고, 다음 한 줄로 거점 단위 재수집이 된다:

```bash
python -m data.collectors.vworld_bldg <거점slug>
```
