## 현재 상태 (2026-08-01 전환 후)
- 지표는 R-ONE 정의에 맞춰져 있다: calibration.json 의 rone_aligned.mid
  (일반건축물 · 상가 주용도 · 3층 이상 또는 330㎡ 초과 · 면적가중 · 층 단위 분자).
- 분자는 층 단위 밴드다. 상한(층 미상 점포·PIP·인허가를 빈 층에 배정) 기준 대표값,
  하한은 층이 확인된 점포만. 13거점 층 밴드는 상한 18.9~31.4% / 하한 38.3~55.5%.
- status 정확도 82.1%(28동 표본).

## 확인된 것 (다시 파지 말 것)
1. 모집단·단위 불일치는 해소됐다(집합 분리 · 상가 주용도 · 면적가중).
2. 분모 정밀화·절단 복구·분자 stale 은 모두 소거됐다.
3. 소규모 세그먼트 일치 → 측정 방식 자체는 맞다. 규모에 비례하는 결손만 남았다.

## 해야 할 일
1. 규모 구간별로 격차를 분해할 것. 분모 층수 1~2 / 3~5 / 6~10 / 11+ 로 나눠
   층 점유율(상한·하한)을 내고, 어느 구간부터 꺾이는지 본다.
   (13거점 층별 점유율 하한은 1층 66.6% · 2층 44.3% · 3층 37.4% · 4층 32.4% · 5층+ 32.5%)
2. 상층부에 실제로 무엇이 있는지 독립 소스로 확인할 것. 상가정보 외에
   인허가(seoul_licensing)·카카오 로컬에 층 정보가 있는지 보고, 있으면 층 단위로
   분자에 합류시킨다. 없으면 상층부는 '미측정'으로 분리 보고하는 편이 정직하다.
3. flrNo 공란 약 30% 를 줄일 수 있는지 볼 것. 상가정보의 hoNo·건물명·도로명주소로
   층을 복원할 수 있는 비율을 재고, 복원분만큼 밴드가 좁아지는지 확인한다.
4. 그래도 남으면 R-ONE 표본 자체의 성격(임대 가능·관리 대상 건물 위주, 상권당 약 16동)
   과 우리 전수의 차이를 정량화해 **격차의 일부는 원리적으로 닫히지 않는다**고
   문서화할 것. α 보정으로 덮지 말 것.

- 로드뷰 재표본이 필요하면 **층화 기준은 분모 층수**(1~2 / 3~5 / 6~10 / 11+),
  거점은 격차 양극단(songridan +3.5 vs seochon +23.7)을 포함할 것.
