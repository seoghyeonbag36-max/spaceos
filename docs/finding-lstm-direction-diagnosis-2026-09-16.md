# [실측] 공실 예측 방향 축은 왜 미달인가 — 모델이 아니라 **표본 쏠림**이다 (2026-09-16)

## 한 줄

방향 KPI 실패(−7.7%p)는 "모델이 쓸모없다"가 아니다. 모델은 **소수 클래스(상승)에
실제 신호가 있고**(MCC +0.278), 지는 이유는 홀드아웃이 51:14로 쏠려 있어 **원시
정확도가 상수 규칙에 유리**하기 때문이다. 그리고 표본 65건으로는 어느 쪽이 나은지
**원리적으로 못 가른다**(표준오차 5.7%p).

선행 문서: [finding-kpi-leak-2026-09-16.md](finding-kpi-leak-2026-09-16.md)

## 혼동행렬 (상승=양성, 홀드아웃 65건)

|  | 실제 상승 | 실제 하락 |
|---|---|---|
| **예측 상승** | TP 8 | FP 13 |
| **예측 하락** | FN 6 | TN 38 |

| 지표 | 모델 | 무정보 상수('항상 하락') |
|---|---|---|
| 원시 정확도 | 70.8% | **78.5%** |
| **균형정확도** | **65.8%** | 50.0% (정의상) |
| **MCC** | **+0.278** | 0 (정의상) |
| 상승 재현율 | 57.1% (8/14) | 0% (0/14) |
| 상승 정밀도 | 38.1% | — |
| 하락 재현율 | 74.5% (38/51) | 100% |

읽는 법: 상수 규칙은 **상승 14곳을 하나도 못 맞히고도** 78.5%를 받는다. 모델은 그중
8곳을 잡고, 상승 정밀도 38.1%는 기저율 21.5%의 1.8배다 — 무작위가 아니다. 균형정확도와
MCC 는 상수 규칙이 구조적으로 각각 50%·0 이므로, 이 두 값이 그 위에 있다는 것이
**신호의 존재**를 원시 정확도와 독립적으로 말해 준다.

## 임계값을 옮기면?

방향 판정은 `pred > prev`(임계값 0)다. 홀드아웃에서 임계값을 훑으면 `delta > 0.997`
에서 **80.0%** 로 상수(78.5%)를 넘는다.

⚠ **이 값을 그대로 인용하면 안 된다.** 임계값을 test 에서 고른 것이라, 09-16 에 막은
선택 누수와 **정확히 같은 종류**다. val 에서 고르고 test 에 한 번 써야 하며, 그러면
실제 이득은 80.0% 보다 낮게 나온다. 여기 적는 이유는 "이득이 있다"가 아니라
**"고칠 여지가 임계값에 있다"** 를 가리키기 위해서다.

## 표본이 문제다 — 그리고 거점을 늘리는 것은 답이 아니다

홀드아웃 65건, 이항 표준오차 **5.7%p**. 독립 표본 가정으로 계산하면:

| 가리려는 차이 | 필요한 홀드아웃 |
|---|---|
| 5%p | ≈323건 |
| 3%p | ≈896건 |

거점당 1건이므로 거점 323~896곳이 필요하다(현재 66). **거점 확대로는 못 푼다.**

그런데 **분기는 이미 있다.** 거점당 22분기 · `look_back` 8 → 윈도우 **14개**인데
종전에는 그중 **1개만** 홀드아웃으로 썼다.

| 거점당 test 원점 | 홀드아웃 | 이항 SE |
|---|---|---|
| 1 (종전) | 66 | 5.7%p |
| **3 (현 기본값)** | **198** | **3.3%p** |
| 5 | 330 | 2.5%p |
| 8 | 528 | 2.0%p |

⚠ **이 SE 는 낙관적이다.** 같은 거점의 이웃 분기는 상관돼 있어 표본이 독립이 아니다.
그래서 `scripts/kpi_baseline.py` 는 거점당 표본이 여럿이면 이항 공식 대신 **거점 단위
군집 부트스트랩**으로 구간을 낸다(`ci_kind: "cluster_bootstrap"`). 실제 개선폭은 위
표보다 작고, **얼마나 작은지는 재학습해서 재야 안다.**

⚠ train 윈도우가 거점당 13 → 9 로 준다(66거점 기준 858 → 594). 그 대가는 **미측정**이다.

## 무엇을 하면 되나 (순서)

1. **재학습하면서 두 팔을 같이 돌린다.**
   ```bash
   python -m ml.training.train_lstm                                  # 롤링 3/2 (기본)
   python -m ml.training.train_lstm --test-quarters 1 --val-quarters 1   # 대조군
   ```
   비교할 것: test 방향 실력(vs 상수) · MAE 기술점수(vs 지속성) · 구간 폭.
   train 축소의 대가가 분해능 이득보다 크면 대조군으로 되돌린다.
2. **결정 임계값을 val 에서 보정한다.** test 에서 고르면 누수다.
3. **판정 지표를 바꿀 거면 재학습 *전에* 확정한다.** 균형정확도·MCC 는 상수 규칙이
   못 이기는 지표라 이 과제에 더 맞지만, **결과를 보고 고르면 metric shopping** 이고
   그건 이 저장소가 막아 온 누수와 같은 종류다. 지금은 `kpi_baseline` 의 **관측
   항목**으로만 싣고 판정에는 쓰지 않는다.
