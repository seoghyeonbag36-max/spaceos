# 소상공인365 · 창업 API · MCP 를 붙일 것인가 (2026-09-15)

> 질문: "소상공인365와 같은 창업 관련 API나 MCP 연동 등을 PlaceOS에 추가해야 할까?"
>
> ⚠ **이 문서는 `probe-first` 기준의 1콜 실측이 아니다.** 이 세션의 egress 프록시가
> `data.go.kr` · `bigdata.sbiz.or.kr` · 지자체 공지를 전부 차단했다(§6). 판단은
> **공개 명세 + 이 저장소의 아키텍처 실측**에 기댄 것이고, 뒤집을 수 있는 지점은
> §3-B 하나뿐이다. 그 지점은 반드시 전화 한 통으로 확정해야 한다.

## 0. 판정

| 대상 | 판정 | 근거 |
|---|---|---|
| **소상공인365 상권분석 연동** | ✗ **붙이지 않는다** | §2 — 입도가 거칠고 · 이미 있고 · Iframe 이라 Bronze 에 못 들어간다 |
| 소상공인 계열에서 새로 얻을 것 | 사실상 없음 | §2-2 — 정본(상가정보 API 15012005)은 **이미 저장층에 쓰고 있다** |
| 경기·전국 확장의 구멍을 메우는가 | ✗ **못 메운다** | §3 — 전국 단위인 것은 맞으나 행이 안 나온다 |
| **MCP 를 클라이언트로 붙이기** | ✗ | §4-1 — 계층만 늘고 배포 의존성 제약과 충돌 |
| **PlaceOS 가 MCP 서버를 내기** | ○ **여기가 붙일 값이 있는 쪽** | §4-2 — 배선(엔드포인트·API 키·사용량 계측)이 이미 다 있다 |

한 줄로: **소상공인365 는 붙이지 않는다. MCP 는 붙이되 방향을 반대로 — 소비자가 아니라 공급자로.**

## 2. 기각 사유 셋

### 2-1. 입도가 우리보다 거칠다 — 내리면 그건 합성값이다

`page_building_master` · `floor_vacancy` 는 **건물관리번호(`bdMgtSn`) · PNU · `flrNo` 층 단위**로 돈다.
소상공인365 상권분석은 **행정동 단위**다. 행정동 값을 건물 한 채로 내릴 방법은 없다.

내리면 그건 합성값이고, `city-expand` §5-2 가 명시적으로 금지하는 것이다 —
*"서울 소스를 흉내 낸 합성값 — 없는 구간은 비워 두고 그 사실을 화면에 싣는다."*
이 원칙은 Posting 의 `rone-shared` 배지에서 이미 한 번 집행됐다(`plan-gyeonggi-expansion` §3-B).

### 2-2. 이미 갖고 있다 — 먼저 세지 않으면 같은 것을 두 번 산다

| 소상공인365 가 준다는 것 | 우리가 이미 갖고 있는 것 |
|---|---|
| 점포·업종 분포 | 상가정보 API (15012005) — 저장층 정본 |
| 행정동 추정매출 | 서울 상권분석 `VwsmTrdarSelngQq` (`data/collectors/seoul_trdar.py`) |
| 행정동 유동인구 | 서울 생활인구 + SGIS 집계구 — Posting 유닛 `foot` 까지 배선됨(§0-P) |
| 개·폐업률 | `VwsmTrdarStorQq` + 인허가(`seoul_licensing` · `gg_licensing`) |
| 업종별 비용 구조 | **KOSIS 서비스업조사 `DT_3KB9001`** — KSIC **5자리**까지 (`feature-posting.md` §0-F) |

마지막 줄이 특히 중요하다. 소상공인365 의 상위 소스인 **소상공인실태조사는 업종이 11개 대분류라
숙박·음식점업이 통합돼 tier 수준 세분이 불가능**하고, 그래서 `feature-posting.md` §0-E 에서
이미 **🔴 부적합으로 기각된 소스**다. KOSIS 로 갈아탄 것이 그 결론이었다.

`probe-first` §5: *"이미 있는 것을 다시 수집 과제로 적지 않는다 — 먼저 센다(사흘에 네 번 겪었다)."*

### 2-3. Iframe 은 Bronze 에 못 들어간다

우리 규칙은 Bronze→Silver→Gold 3계층이다(CLAUDE.md). Iframe 은 **렌더된 화면**이라 행이 없다.

```
행 없음 → Bronze 저장 불가 → Gold 산출물 없음
        → LSTM/GNN 피처 불가 · /api/v1 응답 불가 · pppp_status 게이트 계수 불가
```

화면에 iframe 을 꽂는 것 자체는 기술적으로 된다. 그러나 그것은 **소진공의 상권분석 화면을
우리 제품 안에 띄우는 것**이다. "이 입지는 어떤 플랫폼인가"(PPPP 의 첫 질문)에 우리가 아니라
소진공이 답하게 되고, M&A Exit 에서 값이 매겨지는 자산이 그만큼 사라진다.

이 논지는 `finding-map-provider-google-2026-09-15.md` 가 지도 공급자에 대해 내린 것과 같다 —
**남의 표시기가 되는 방향의 연동은 사업화 축에서 손실이다.**

## 3. 진짜 구멍은 따로 있다 — 그런데 거기도 못 메운다

### 3-A. 구멍의 정체

`plan-gyeonggi-expansion-2026-08-29.md` §2-B 의 **"서울 전용 — 교체해야 하는 넷"** 이 실제 구멍이다.
지금 대체재는 **도시마다 포털을 3곳씩 뚫는 구조**다(경기데이터드림 · 공공데이터포털 · 경기도시장상권진흥원).
도시가 늘 때마다 키 3종과 스키마 3종이 는다.

소상공인365 가 **전국 단위**라는 점 때문에 이 패치워크를 하나로 바꿀 후보로 보인다 —
**이것이 이 질문의 가장 강한 논거다.** 값도 크다.

**그러나 §2-3 에 걸린다.** 전국이어도 행이 안 나오면 `gg_trdar.py` 를 대체하지 못한다.
Iframe 은 도시 수와 무관하게 Gold 로 못 간다.

### 3-B. ⚠ 재평가 트리거 — 이것 하나가 판정을 뒤집는다

> **소진공 빅데이터실이 Iframe 말고 JSON 데이터 API 트랙을 여는가?**
>
> 확인 방법: 소상공인365 가입 후 [이용안내 → 오픈API 활용신청] 화면의 제공 형식 확인,
> 또는 소진공 빅데이터실 **042-363-7563** 전화.
>
> 열려 있다면 이 문서의 판정을 **전면 재평가한다** — 전국 단일 스키마는
> §3-A 의 구멍을 도시별 패치워크 없이 메우는 유일한 후보다.
>
> 이것은 **세션이 대신 못 하는 종류의 막힘**이다. 경기데이터드림 인증키와 같은 성격
> (`city-expand` 부록: *"막는 것 — 경기데이터드림 인증키(무료, 회원가입 필요 — 세션이 대신 못 한다)"*).

### 3-C. 곁가지 — 배달 축은 우리에게 정말 없다

소상공인365 설명에 **배달 건수**가 있다. 저장소 실측: 배달 실데이터 **0건**이다.

```bash
grep -rn "배달\|카드매출" --include="*.py" --include="*.md" .   # → 시드 문자열 · ha_guard 브랜드명뿐
```

이것은 `feature-posting.md` §0-G 의 미해결 지점과 맞닿아 있다 —
**매출의 면적 기울기**(배달 비중이 높은 업종은 매출이 면적에 비례하지 않는다).

그러나 (가) 역시 Iframe 이고, (나) KOSIS §0-F 가 이미 영업비용률을 KSIC 5자리로 주고 있어
배달이 새로 풀 것은 비용이 아니라 **매출 쪽**이며, (다) 우선순위로는 GNN 천장 37%대
(막힘 6·17, 네 번 확인됨)보다 아래다. **지금 착수하지 않는다.**

## 4. MCP — 방향을 뒤집어야 한다

### 4-1. 클라이언트로 붙이는 것 — ✗

| 이유 | 근거 |
|---|---|
| 형태가 안 맞는다 | `data-go-mcp-servers` 류는 전부 Claude Desktop/Code 용 **로컬 stdio MCP** 다. 우리 수집은 Airflow 배치 + `requests` 직호출 + Bronze 저장이라 계층만 하나 는다 |
| **배포 제약과 충돌한다** | `posting_copilot.py` 헤더가 못 박은 규칙: *"표준 라이브러리만 쓴다 — 의존성이 fastapi/pydantic 뿐이라 httpx 를 쓰면 프로덕션에서만 죽는다"*. Node 런타임 MCP 를 Cloud Run 에 얹는 것은 정면 충돌 |
| 프로브용으로도 더 비싸다 | `probe-first` §2: *"새 코드를 짜서 재면 '그 코드가 맞나'가 다음 질문이 된다."* `python -c "from data.collectors... "` 한 줄이 더 싸다 |
| 개발 도구로는 **이미 쓰고 있다** | `.mcp.json` — postgres · filesystem · github 3종 |

### 4-2. 서버로 내는 것 — ○ (붙일 값이 있는 쪽)

**근거 넷:**

1. **배선이 이미 다 깔려 있다.** `/api/v1` 엔드포인트 30여 개 + API 키 발급(`/auth/api-keys`)
   + 사용량 계측(`api/deps.py:track_access` → `services/usage.record_access`) + `/admin/usage`.
   MCP 서버는 그 위의 **얇은 툴 표면 하나**다. 새로 지을 인증·계측이 없다.
2. **DaaS 의 실제 사용 형태와 맞는다.** 프랜차이즈 본사 담당자가 대시보드를 배우는 것보다
   "가로수길 1층 60㎡ 공실 중 회수기간 24개월 이내인 자리"라고 묻는 게 빠르다.
   `usage.py` 가 재려는 **KPI② PMF** 가 정확히 그 사용을 센다
   (*"파일럿이 실제로 무엇을 얼마나 썼나"를 셀 자리가 없으면 목표는 관측 없이 선언만 남는다"*).
3. **`spaceos.posting/1` 계약과 철학이 같다.** `posting_copilot.py` 가 이미 한 번 뒤집었다 —
   *"방향을 뒤집는다 — PlaceOS 가 계약을 발행하고 공급자가 여기에 맞춘다."*
   소상공인365 를 소비하면 우리는 소진공 데이터의 표시기가 되고,
   MCP 서버를 내면 우리가 **남의 에이전트가 붙는 자리**가 된다. Exit 에서 값이 매겨지는 건 후자다.
4. **외부 코파일럿 자리가 07-18 이후 여전히 비어 있다**(`POSTING_COPILOT_URL` 미설정).
   MCP 서버를 내면 공급자가 REST 대신 MCP 로 붙을 수도 있고,
   계약 v1 의 경계표(누가 `invest_mn` 을 주고 누가 `recommended` 를 정하는가)를 그대로 재사용한다.

### 4-3. 범위 — 착수한다면 이만큼

| 항목 | 내용 |
|---|---|
| 툴 | **읽기 전용 5종** — `list_districts` · `district_summary` · `floor_vacancies` · `simulate_posting` · `industry_fit` |
| 구현 | `app/services/*` **함수 직접 호출**(HTTP 재진입 아님). 응답 스키마는 `app/schemas/` 그대로 |
| 인증·계측 | 기존 API 키 재사용 · `track_access` 와 같은 자리에서 계측 |
| 게이트 | `scripts/pppp_status.py` 에 `[자동]` 하나 — **"MCP 툴 5종이 실제 Gold 산출물을 돌려준다"** |
| 의존성 | MCP Python SDK 가 현행 `requirements.txt` 위에 얹히는지 **먼저 확인**. 안 되면 별도 사이드카 |

**하지 않을 것:** 쓰기 툴 · 새 런타임 의존성 무단 추가 · 시드로 채운 응답.

## 5. 결정 요약 (다음 사람에게)

1. 소상공인365 는 **연동 후보에서 내린다.** 다시 올라오면 이 문서 §2 를 먼저 읽는다.
2. 소상공인실태조사 계열은 `feature-posting.md` §0-E 에서 **이미 한 번 기각**됐다 — 세 번째 시도를 막는다.
3. 재평가 트리거는 §3-B **하나**다. 그 전화 한 통 전에는 재론하지 않는다.
4. 배달 축(§3-C)은 **실재하는 구멍이지만 지금 순위가 아니다.** GNN 천장(막힘 6·17) 뒤다.
5. MCP 는 **서버 방향으로만** 검토한다(§4-2). 클라이언트 방향은 §4-1 에서 닫혔다.

### 6-2. ⛔ 실행하지 못한 프로브 — egress 차단

| 대상 | 결과 |
|---|---|
| `https://bigdata.sbiz.or.kr/` | **EGRESS_BLOCKED** (프록시 차단) |
| `https://www.data.go.kr/data/15143517/fileData.do` | **EGRESS_BLOCKED** |

`fileData.do` 라는 URL 경로 하나만이 1차 근거에 가깝다(공공데이터포털이 파일셋과 API 를 경로로 가른다).

**다음 사람이 반박하려면**: 소상공인365 에 가입해 [오픈API 활용신청] 화면의 제공 형식을 직접 보고,
JSON 응답이 나오면 그 응답 1건을 `reports/sbiz365_probe.json` 에 남긴 뒤 §0 판정을 뒤집는다.
