# PlaceOS 논문 작업 전체 단계

이 문서는 작업 단계와 산출물의 상태를 설명한다. 새 논문 실험 결과나 제품 진행률을 선언하지 않는다. 각 P는 같은 절차를 따르되 데이터·타깃·모집단을 별도로 정의한다. 현재 연구의 우선 대상은 Page이며, [연구 진행 기록](page-study/README.md)과 [조건 D 근거](evidence-index.md#page-condition-d)의 2026-09-07 상태를 반영했다.

| 단계 | 작업·완료 기준 | 현재 상태 | 산출물 |
|---|---|---|---|
| 환경 준비 | 저장소 접근, 인터넷, 필요한 분석 도구 확인 | 사용자 제공 클라우드 점검 기록과 별도 로컬·PC 검증 기록 있음. 클라우드 실행 검증 완료를 뜻하지 않음 | [데이터 명세의 인계 기록](data-specification.md), [PC 세션 기록](page-study/README.md) |
| 데이터 명세 | 원천·키·단위·시점·가공·출처·한계 정리 | 초기 명세 작성 완료. 전수 데이터 검증과 다름 | [data-specification.md](data-specification.md) |
| 문헌 후보·뼈대 검증 | 서지, 원문, 분야·연도별 Q1, 데이터·방법 적합성 확인 | Page 핵심 저자 공개본의 페이지별 검토·방법 근거표 작성. 최종 출판본·별도 부록·보조문헌 전체 본문은 미확보. 모든 P 최종 확정은 미완료 | [읽기 장부](page-study/reading-ledger.md), [원문 등록](page-study/source-register.json), [문헌 후보](literature-candidates.md), [뼈대 선정](backbone-selection.md) |
| 연구 설계 | 연구 질문→변수→분모→평가 절차→한계 연결 | Page는 계산 재현성·데이터 품질 범위와 변수 대응 확정. 현실 공실 정확도·정정 효과는 이번 실증 범위에서 제외. 다른 P의 설계는 후속 대상 | [현재 설계와 변수](page-study/design-and-variables.md), [기존 프로토콜](page-data-quality-protocol.md) |

| 근거 등재 | 수치마다 코호트·분자·분모·원천·재현 경로 등재 | Page 조건 D의 구조 감사·계산 재현성·순서 민감도·층 배정 범위와 미평가 항목 등재 완료 | [조건 D 근거 인덱스](evidence-index.md#page-condition-d) |
| 논문 작성·검토 | 검증한 문헌과 등재된 근거로 절별 작성, 한계·기각 유지 | Page §2.4 방법론·§3 조건 D 결과 작성 완료. 나머지 Page 절과 다른 P 원고는 뼈대. 기존 유동·해상도 장은 조건 D와 다른 범위로 후속 정리 | [Page 원고](paper-page.md), [집필 기록](page-study/README.md) |
| 제출물 준비 | 인용·연구윤리·기여·재현 자료 검토 후 문서 형식 완성 | 미진행 | 제출 용도별 원고·포트폴리오 |

문헌 검증은 절별 집필과 병행할 수 있다. 하지만 미확인 문헌을 확정 인용하거나 Q1 게재 논문을 참고했다는 이유로 작성한 원고 자체를 Q1 수준이라고 판정하지 않는다. Page 저자 공개본의 확인 범위와 판본별 미확보 상태는 [읽기 장부](page-study/reading-ledger.md)에 기록돼 있으며, 최종 출판본·별도 부록 대조는 남아 있다.

## 원천 인벤토리 작성 당시 작업 계약

아래는 원천 인벤토리 작성 단계의 기존 실행 계약이다. 현재 완료 상태나 후속 집필 범위는 위 표와 아래 후속 작업을 따른다.

- 대상: 이 문서, `build_page_audit_manifest.py`, `audits/page-inventory-20260906/manifest.json`, `inventory.csv`, `manifest.sha256`, `README.md`.
- 입력: 동결한 `ACTIVE_HUBS` 범위의 Page 핵심 원천·중간 산출물·Gold, R-ONE 공실 보조자료, 관련 코드·환경 버전. 관측 시점 미확인은 그대로 남긴다.
- 검수: `manifest_digest_matches`, `manifest_file_fingerprints_match`, `manifest_selector_matches_loader`, `manifest_inventory_matches`, `manifest_cohort_matches_registry`, `manifest_unknowns_preserved`.
- 금지: 원천·제품 코드 수정, 원천 API 재수집, 미측정값 보완, Gold 재빌드, 자동 커밋·푸시. 파일 해시 포착을 과거 입력의 증명이나 불변 사본 생성으로 표현하지 않는다.

## 현재 후속 작업

계산 재현성·데이터 품질을 우선한다는 [확정 연구 범위](page-study/design-and-variables.md)에 따라, 이미 등재한 조건 D 근거와 작성한 방법론·결과를 바탕으로 다음을 진행한다.

1. **원고 절별 보완:** 서론·데이터 설명·논의·결론은 대상 절, 입력 근거, 검수 조건, 금지 사항을 정한 뒤 한 절씩 작성한다. 기존 유동·해상도 장은 조건 D와 다른 연구 범위로 남아 있으므로, 처리 방향을 정하기 전에 두 분석의 효과를 합치지 않는다.
2. **문헌 확인 범위 보완:** 최종 출판본·별도 부록·보조문헌 전체 본문을 확보하면 원문 등록과 페이지별 방법 근거표를 보완한다. 확보 전에는 미확보·판정 불가 상태를 유지한다.

독립 현실 정답과 사람 판정은 현재 실증의 필수 선행 작업으로 두지 않는다. 추후 현실 공실 정확도·오류 수정 효과 연구를 재개할 때는 관측시점이 맞는 참조자료, 검토자의 독립성과 불일치 처리 규칙부터 별도로 확정한다. 기존 미판정 필드는 그대로 둔다.

현재 안내 문서의 갱신은 기존 산출물의 상태를 반영한 것이며 새 분석 실행이 아니다. 변경된 입력이 있으면 이전 실행에 섞지 않고 새로운 run-id로 재포착한다. 이전 새 체크아웃과 PC 실행의 입력 보유량·환경 기록을 각각 보존하고, Gold→서빙 검증을 전체 Bronze→Silver→Gold 파이프라인이나 클라우드·독립 팀 재현으로 확대하지 않는다.

행 순서 시험은 기존 사후 탐색이며 독립 표본·사전등록 검정이 아니다. 원천 관측 시점 정렬은 미평가이고, 보관일·가공일로 관측 시점을 대신하지 않는다.
