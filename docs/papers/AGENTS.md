# AGENTS.md — docs/papers (논문)

루트 [AGENTS.md](../../AGENTS.md) 를 먼저 읽는다. 이 문서는 이 디렉터리에만 더 얹는 규칙이다.

여기는 **코드가 아니라 글**이다. 저장소의 다른 규칙(테스트 통과·빌드)이 통하지 않으므로
통과 조건을 다르게 정의한다.

## 이 디렉터리에서 절대 하지 않는 것

1. **[evidence-index.md](evidence-index.md) 에 없는 수치를 본문에 쓰지 않는다.**
   근사치·"약 X%"·반올림한 기억도 안 된다. 인덱스에 있는 값을 그대로 옮긴다.
2. **선행연구를 지어내지 않는다.** 저자·연도·학회명을 생성하지 않는다.
   문헌이 필요한 자리는 `<!-- TODO(문헌): 무엇이 필요한지 -->` 로 비워 둔다.
   **그럴듯한 가짜 인용이 이 디렉터리에서 가능한 최악의 산출물이다.**
3. **음성 결과를 양성으로 고쳐 쓰지 않는다.** "기각됐다"를 "추가 연구가 필요하다"로
   바꾸는 것도 고쳐 쓰는 것이다.
4. **`docs/feature-*.md` 나 `reports/*.json` 을 수정하지 않는다.** 여기서는 읽기만 한다.
   원본 수치가 틀렸다고 판단되면 고치지 말고 논문 파일에 `<!-- 확인필요: ... -->` 를 남긴다.
5. **모집단이 다른 수치를 한 표에 섞지 않는다.** 인덱스 맨 위의 조건 A/B/C 표를 볼 것.
   54거점 실험값과 66거점 서빙값은 비교 가능하지 않다.

## 통과 조건 (테스트 대신)

이 디렉터리의 변경은 아래를 만족해야 머지된다.

- [ ] 본문에 등장하는 **모든 수치**가 `evidence-index.md` 에서 grep 으로 찾아진다
- [ ] 인용이 하나라도 있다면, 전부 실제로 확인한 문헌이다 (아니면 TODO 로 비어 있다)
- [ ] `<!-- FILL -->` 를 지웠다면 그 자리가 실제로 채워졌다 (빈 채로 표시만 지우지 않는다)
- [ ] 기각·한계·미측정이 본문에 남아 있다 (요약하면서 증발시키지 않았다)

검사 방법:

```bash
# 본문의 퍼센트·수치를 뽑아 인덱스와 대조한다
grep -oE '[0-9]+\.[0-9]+%?|[0-9]{3,}' docs/papers/paper-*.md | sort -u
```

## 한 번에 하나의 절만 채운다

논문 전체를 한 번에 생성하지 않는다. **절 하나 = 커밋 하나**가 이 디렉터리의 단위다.
이유: 근거 대조가 절 단위로만 가능하고, 통째로 생성한 글은 어디서 수치가 새는지 알 수 없다.

작업 요청은 이 형태로 받는다:

```
paper-platform.md 의 §3.2(성능 천장 4회 확인)만 채운다.
근거: evidence-index.md 의 "성능 천장 — 4회 독립 확인" 표.
분량: 400~600자. 표는 인덱스 것을 그대로 옮긴다.
금지: 그 표 밖의 수치 · 문헌 인용.
```

## 언어와 형식

- **한국어**, 기술 용어는 영문 병기 (저장소 규칙과 동일)
- 목표는 학술 논문 포트폴리오 → **문제의식 · 방법 · 기여**가 드러나게
- 최종 산출물이 `.docx` 로 나갈 경우 한글 폰트 임베딩이 필요하다
  → `memory/context/docx-korean-fonts.md` (폰트명만 지정하면 프리뷰에서 박스로 깨진다)
