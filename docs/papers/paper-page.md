### 2.4 구조 일관성·계산 재현성·순서 민감도의 평가 절차

본 연구는 공공행정자료를 결합한 가공 산출물의 계산적 성질을 평가한다. Alsudais의 저자 공개본에서 확인한 객체 의미 대조와 릴리스 특정의 절차를 참고하되, 원문 자료와 SpaceOS 자료의 관측 단위가 같다고 가정하지 않는다. 원문 검토의 판본·페이지와 적용 변경은 [방법 근거표](page-study/reading-ledger.md)에 기록한다. 출판본 및 별도 부록 대조는 미완료이며, 원문의 수치나 통계 검정 결과를 성능 기준으로 사용하지 않는다.

분석 입력은 원천 경로·선택 규칙·파일 해시를 가진 인벤토리로 특정한다. 표시 객체인 폴리곤과 집계 객체인 지번을 구분하고, 현행 출처·분모·도형 조건을 통과하는 지번만 대표 집계에 포함한다. 원천 관측 시점이 없으면 보관일이나 가공일로 대체하지 않는다. 구조 검사는 식별자, 분자·분모 범위, 계산식 및 층 정보의 일관성을 대상으로 하며, 규칙별 적용 분모와 미평가를 함께 보고한다. 동일 지번 내 서로 다른 폴리곤의 값 차이를 확정 오류로 취급하지 않는다.

재현성은 고정 입력 반복과 새 체크아웃의 서빙 실행으로 평가한다. 반복 마스터는 바이트와 객체 값을 각각 비교하며, 커버리지의 생성시각은 사전에 지정한 제외 항목으로 구분한다. 서빙 응답은 필드를 제외하지 않고 전체 객체를 비교한다. 별도의 검산은 저장된 셀의 수용량·활성값·공실량을 합산하여 거점 응답과 대조한다. 새 체크아웃 시험은 배포 Gold에서 서빙까지의 재현 범위이며, 원천 재수집부터의 전체 파이프라인 재현과 구분한다. 실행기·환경·입력 및 로드한 코드의 해시는 함께 보존한다.

순서 민감도는 내용이 같은 폴리곤을 역순·식별자 순·고정 난수 순으로 입력한 기존 탐색 시험을 대상으로 한다. 거점 전체 집계, 격자 진입·이탈, 공통 격자의 분자·분모 변화를 구분하고, 반복 변형을 독립 표본으로 세지 않는다. 층 미확정 정보에 따른 공실 상·하한은 배정 가능한 범위이며 통계적 신뢰구간이 아니다. 이미 관찰한 결과에 대한 분석임을 밝히고 사전등록 가설검정으로 소급하지 않는다. 독립 현장 정답이 없어 현실 공실 정확도·오류 수정 효과는 추정하지 않는다. 본 절의 실행 범위와 수치 근거는 [근거 인덱스 조건 D](evidence-index.md#page-condition-d)와 [재검증 기록](page-study/evidence-verification.json)에 연결한다.

## 3. 조건 D 결과

### 3.1 구조 일관성 검사

동결된 가공 마스터의 검사 범위는 66거점, 52,642 폴리곤이다. 식별자·계산식에 대한 구조 감사와 층 정보 검사는 적용 분모를 구분하며, 층 정보 검사의 대상은 30,912 폴리곤이다. 이 결과는 가공 산출물 내부의 일관성에 관한 것으로, 구조 검사 통과가 현실 공실 정답 확인을 뜻하지 않는다. 같은 지번의 서로 다른 폴리곤도 자동으로 확정 오류라고 부르지 않는다. [근거: PAGE-D01·D02 및 조건 D의 동일 지번 판정 제한](evidence-index.md#page-condition-d)

### 3.2 고정 입력 계산 재현

기존 별도 프로세스 반복에서는 마스터·커버리지·서빙이 66/66 일치했다. 마스터는 바이트와 객체 값을 비교했고, 커버리지는 생성시각인 `built_at`만 제외했으며, 서빙은 전체 응답 객체를 비교했다. 보존 서빙 사본 비교와 셀 독립 재합산도 각각 66/66 통과했다. 이때 독립 재합산은 저장된 셀의 수용량·활성값·공실량을 다시 합산한 계산 검산이며, 독립 현장 조사나 독립 연구팀의 재현을 의미하지 않는다. [근거: PAGE-D04·D08](evidence-index.md#page-condition-d)

이전 새 체크아웃에서는 보존 감사 파일 224개가 해시와 일치했고, Gold→서빙 비교가 66/66 일치했다. 해당 체크아웃의 원본 인벤토리 946개 중 보유는 265개, 미보유는 681개였다. 검증 범위는 Gold→서빙이며 Bronze→Silver→Gold 전체 재현이 아니다. 이번 PC 작업 디렉터리의 재검증에서도 서빙 비교·셀 재합산·Gold→서빙 비교는 각각 66/66 통과했다. 다만 PC의 원본·감사 파일 보유 범위는 이전 체크아웃과 다르므로 실행 기록을 분리했다. 이 PC 실행을 새로운 체크아웃 시험이나 원천 재수집으로 세지 않는다. [근거: PAGE-D09–D12](evidence-index.md#page-condition-d), [환경별 실행 기록](page-study/evidence-verification.json)

### 3.3 순서 민감도

기존 행 순서 시험 198회에서 거점 전체 집계 변화는 0회였지만, 65거점에서 격자 소속 또는 분자·분모 영향이 있었다. 따라서 이 입력 묶음에서 전체 집계가 같았다는 사실만으로 격자 출력까지 순서에 불변이라고 판단할 수 없다. 이 시험들은 동일 내용을 역순·식별자 순·고정 난수 순으로 변형한 기존 사후 탐색 결과이며, 독립 표본이나 사전등록 가설검정이 아니다. 현실 위치 오차나 오류 수정 효과도 이 결과로 추정하지 않는다. [근거: PAGE-D05](evidence-index.md#page-condition-d), [순서 시험 재집계](page-study/evidence-verification.json)

### 3.4 층 정보 미확정에 따른 범위

층 배정에 따른 공실 범위 폭은 중앙값 16.235267101643892%p, 최댓값 34.38818565400844%p였다. 이는 층 정보 부족에 따라 배정 가능한 상·하한의 계산 범위이며, 통계적 신뢰구간이나 현실 공실 오차의 추정치가 아니다. 원문 연구의 수치·확률분포·임계값을 이 범위의 성능 기준으로 사용하지 않았다. [근거: PAGE-D06](evidence-index.md#page-condition-d), [방법 적용 제한](page-study/reading-ledger.md)

### 3.5 검증 범위와 미평가 항목

독립 검토용 표본 211개는 전부 `unresolved`이며, 독립 현장 정답이 없으므로 현실 공실 정확도와 오류 수정 효과는 추정하지 않는다. 원천 관측 시점 정렬은 66거점에서 평가 불가였다. 누락된 관측 시점을 보관일 또는 가공일로 대체하지 않으며, 계산 재현 성공을 최신성·동시점 현실 확인으로 확대하지 않는다. [근거: PAGE-D03·D07](evidence-index.md#page-condition-d)

핵심 문헌의 최종본·별도 부록·저자 원자료·코드와 보조문헌의 전체 본문은 미확보다. 공개본에서 발견한 불일치는 최종 출판본의 확정 오류로 판정하지 않는다. 본 결과는 조건 D의 동결 입력과 계산 절차에 한정하며, 기존 유동·해상도 분석과 결합한 효과, 전체 파이프라인 재현, 클라우드 실행, 독립 팀 재현은 주장하지 않는다. [문헌 확인 범위](page-study/reading-ledger.md), [조건 D 해석 범위](evidence-index.md#page-condition-d), [미평가 항목](page-study/evidence-verification.json)
