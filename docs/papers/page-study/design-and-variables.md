# Page 계산 재현성·데이터 품질 연구: 범위와 변수 대응

2026-09-07 사용자 확인: 현장조사·임대관리 자료와 독립 검토자가 현재 없다. 따라서 **현실 공실 정확도와 정정 효과는 이번 실증 범위에서 제외**하고, 계산적 속성·구조 일관성·순서 민감도를 연구한다. 기존 [프로토콜](../page-data-quality-protocol.md)의 미실행 표시는 설계 당시 기록이며, 실제 수행 범위는 [실행 기록](../audits/page-analysis-20260906/README.md)을 따른다.

## 연구 질문과 판정

| 질문 | 관측·비교 단위 | 판정 방법 | 현재 분석의 성격 |
|---|---|---|---|
| RQ-C1. 고정 입력을 사용한 계산이 재현되는가? | 동일 거점·동일 입력의 출력 객체 | 마스터·서빙 결과의 구조·값 비교. 생성시각 제외 여부 사전 명시 | 기존 반복 실행과 새 체크아웃의 Gold→서빙 확인. 원천 API 재수집 재현 아님 |
| RQ-C2. 같은 내용의 폴리곤 행 순서에 출력이 불변인가? | 거점×순서 변형; 격자는 거점 내부 하위 단위 | 내용은 보존하고 순서만 바꾼 기존 시험에서 전체 집계·격자 소속·분자·분모 비교 | 기존 결과를 이미 본 사후 탐색. 독립 확인 연구나 최대 변동 탐색으로 포장하지 않음 |
| RQ-C3. 데이터 품질의 어떤 항목을 검증하거나 미평가로 남겨야 하는가? | 규칙×적용 프레임 | 규칙별 통과·실패·미평가 분모와 제외 사유 보고 | 기존 구조 감사 및 보존 산출물의 검산. 현실 오류율은 산출하지 않음 |

검증할 계산적 명제는 ‘동일 조건에서는 의미 출력이 같다’ 및 ‘동일 내용의 순서 변화에도 지정 출력이 같다’이다. 전수 프레임에서 관측한 성립·반례를 보고하므로 임의의 유의확률을 붙이지 않는다. 다른 거점·다른 시점·다른 구현으로의 일반화는 별도 검증이 필요하다.

## 변수와 근거 대응

| 개념 | PlaceOS 변수·단위 | 근거 | 분석 시 처리 |
|---|---|---|---|
| 객체 정체성 | `id`: 폴리곤; `pnu`: 지번 | Gold 마스터, `structural-audit.json` | 서로 다른 단위를 같은 표본 수로 합하지 않음 |
| 출처·분모 경로 | `source`, `capacity_method` | Gold 속성, 현행 서빙 코드 | 현행 집계 제외 규칙 유지. 제외 객체를 확정 오류로 세지 않음 |
| 계산 공실 | `capacity`, `active`, `vacancy_rate` | 현행 가공식·서빙 결과 | 단위별로 해석. 실측 공실 정답으로 사용하지 않음 |
| 시간·버전 | 원천 관측 시각, 보관 폴더, `built_at`, 파일 해시 | 동결 인벤토리 | 보관일·가공일을 관측일로 대체하지 않음 |
| 재현 출력 | 객체 필드와 전체 응답 | `reproduction-comparison.json`, 보존 서빙 파일 | 바이트와 의미 비교 구분. 해시만으로 데이터 접근을 보증하지 않음 |
| 공간 출력 | 셀 `(i,j)`, `capacity`, `stores`, `vac_n`, `v` | `baseline-serving`, `order-sensitivity.json` | 셀 진입·이탈과 공통 셀 변화 구분. 같은 거점 반복을 독립 표본으로 늘리지 않음 |
| 층 미확정 영향 | 공실 상·하한, `range_width_pp` | `impact-intervals.json` | 정보 부족에 따른 배정 범위. 통계적 신뢰구간·현실 오차가 아님 |
| 판정 가능성 | 규칙별 `pass/fail/not_evaluable` | `structural-audit.json` | 적용 분모와 미평가를 함께 유지 |
| 독립 현실 정답 | `review_label`, `reference_observed_at` | 기존 검토 표본 | 현재 전부 미판정. 사용자 확인에 따라 이번 실증 목표에서 제외 |

## 이번 검증의 실행 경계

`verify_evidence.py`는 이전 감사 코드를 호출하지 않고 보존 파일의 해시와 셀 합계를 계산한다. 이어 새 Git 체크아웃의 실제 서빙 함수를 실행하여 보존 응답과 전체 객체를 비교한다. 두 검사에서 독립적인 것은 집계 계산 경로이며, 연구자·원천 데이터가 독립적이라는 뜻은 아니다.

이 실행은 과거 발견을 확인하는 재검증이다. 실행기·환경·입력 해시와 체크아웃 커밋을 저장한다. 원문 수치 불일치에 대한 검산은 문헌 검토이며 PlaceOS 결과로 합산하지 않는다. 본문 작성은 검증 결과를 근거 인덱스에 먼저 등록한 뒤 진행한다.

## 재현 패키지와 아직 필요한 자료

- 지금 제공하는 것: 문헌 접근·페이지 기록, 방법·변수 대응, 원래 감사 코드와 Git 보존 결과, 추가 검산 실행기·결과, 원고 방법론 절.
- 이번에 직접 실행하는 범위: 새 로컬 체크아웃의 Gold→서빙. 클라우드에서 실행한 결과라고 부르지 않는다.
- Bronze→Silver→Gold 전체 재현에는 인벤토리에서 누락으로 표시되는 원본을 사용 가능한 보관소에 확보해야 한다. Git에 없는 파일을 새 API 응답으로 조용히 대체하지 않는다.
- 원문 최종본·부록, 보조문헌 전체 본문은 미확보다. 계산적 연구를 진행할 수 있지만 원문 실험의 완전 재현 완료를 선언할 수는 없다.

추후 현실 검증을 재개할 때는 기존 확률표본에 관측시점이 맞는 참조자료를 연결하고, 검토자의 역할과 독립성·불일치 처리 규칙을 먼저 정한다. 현재 미판정 필드는 채우지 않는다.
