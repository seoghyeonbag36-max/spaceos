# 고양·파주 주요 상권 판정 (2026-08-30)

## 결론

서빙 목록은 서울 시드 54개를 바꾸지 않고 Gold가 선 경기 거점을 더한다. 고양·파주에서
실측 경계를 확정한 7곳은 모두 Tier1 Gold로 서며, 라페스타와 웨스턴돔은 서로 다른
**예외 서빙** 거점이다. 감성·리뷰·LSTM 예측은 경기 소스가 없으므로 계속 `null`이다.

`top10`은 같은 필터에서 상위 10개 지번이 차지하는 비율이다. 표시 건물 수와 Tier는 각
`data/gold/{slug}/coverage.json`에서 읽었다. `floor_approx`·`expos_units`·`polygon_only`를
API 대표 공실률에 넣지 않는 기존 규칙은 바꾸지 않았다.

## 라페스타와 웨스턴돔을 합치지 않은 근거

- 카카오 로컬로 공식 도로명주소를 대조한 중심은 라페스타
  `126.768308, 37.661029`, 웨스턴돔 `126.772184, 37.655885`다.
- 각 거점은 폴리곤 250m·점포 350m 반경을 쓴다. 이 범위의 점포 건물 id 중복은 2동이다.
- 둘 다 건물당 점포 10개 기준을 넘으므로 정상 채택으로 포장하지 않는다. API `caveat`는
  “예외 서빙”과 일반건축물 표본 한계를 반드시 전달한다.
- 라페스타의 이전 합산 중심점 대장 원본은 덮어쓰지 않고
  `*.stale-combined-20260830.bak`으로 보존했다.

## 도시 전체 후보군 처리

후보군의 단일 경계는 고양 2035 도시기본계획과 파주 2040 도시기본계획의 중심지 체계다.
그중 현재 상권 중심과 실측 반경을 확정한 곳만 위 7곳에 채택했다. 아래 이름은 도시계획상
중심지이거나 공식 상점가 후보이지만, 이름만으로 임의 중심·반경을 만들 수 없어 이번 서빙
목록에는 넣지 않았다. 이것은 값 누락이 아니라 **근거 없는 거점 생성을 막은 판정**이다.

- 고양 미채택: 대곡, 삼송, 원당, 대화·킨텍스, 장항, 풍동, 관산, 고양동, 덕은,
  창릉, 주엽, 백석, 능곡, 행신, 덕이, 향동, 가좌.
- 파주 미채택: 교하·운정중앙, 문산, 조리·봉일천, 탄현면, 월롱, 광탄, 파주읍,
  법원, 적성, 파평, 군내, 헤이리·프로방스와 운정 내부 상점가.

이 후보를 추가하려면 같은 1차 프로브(점포/건물, top10 지번)와 주의 후보의 대장 비중을
먼저 확보한다. 도시계획 명칭을 좌표나 공실값으로 대신하지 않는다.
