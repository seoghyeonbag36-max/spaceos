# Codex 로 내보내기

역할 분담(`CLAUDE.md`):

| 에이전트 | 맡는 것 | 브랜치 |
|---|---|---|
| **Claude Code** | 설계·근거 판단·다파일 리팩터 | `feat/*` |
| **Codex** | **명세가 확정된** 실행 | `chore/*` · `fix/*` |

지침 원본은 `AGENTS.md`.

## 내보내기 전 4항목 — 하나라도 못 채우면 그 작업은 Claude Code 몫이다

1. **대상 파일** — 건드릴 경로를 전부. "적당히 찾아서"는 명세가 아니다.
2. **입력 소스와 출처 표기** — 어느 API·어느 Bronze 산출물인지, 주석에 어떻게 남길지.
3. **통과 조건** — 실행할 **테스트 이름**. `pytest -k ...` 로 지목할 수 있어야 한다.
4. **금지 사항** — 건드리면 안 되는 것(시드 값 조작·기존 gold 덮어쓰기·`--force` 등).

이 4개가 채워지지 않는다는 것은 **판단이 남아 있다**는 뜻이고, 판단은 위임 대상이 아니다.

## 머지 전

```bash
python scripts/run_full_verify.py
```

Codex 산출물은 머지 전 `verify` — **특히 값이 새로 채워진 곳**을 본다. 빈칸이 채워졌으면
그 값이 어디서 왔는지 묻는다. 이 저장소가 지켜 온 원칙은 **합성값을 실측처럼 보이지
않게 하는 것**이다(`vacancy_source`·시드 배지·`rone-shared`).
