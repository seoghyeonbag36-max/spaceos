PlaceOS AI 모델 작업을 수행한다. 대상: 호출 인수(학습·수정할 모델). 비어 있으면 무엇을 돌릴지 먼저 묻는다.

규칙:
1. 모델 정의는 `ml/models/{lstm,gnn}/`, 학습 스크립트는 `ml/training/`.
2. 실험·하이퍼파라미터·메트릭은 MLflow로 추적.
3. **판정은 임계값이 아니라 베이스라인 대비 실력이다**(2026-09-16 KPI 재정의).
   - 학습을 마치면 `python scripts/kpi_baseline.py` 를 돌린다. 미달이면 종료코드 1 이다.
   - 새 지표를 보고할 때는 **같은 분할의 무정보 베이스라인을 반드시 옆에 적는다**
     (공실 예측: 다수 방향 상수 · 지속성 / 업종 추천: 거점 사전분포).
   - 옛 '정확도 70%+' 는 폐기했다 — 무정보 규칙이 그 선을 이미 넘어 모델을 보증하지
     못했다. → `docs/finding-kpi-leak-2026-09-16.md`
   - **선택 ≠ 보고**: 하이퍼파라미터는 val 로 고르고 test 는 보고에만 한 번 쓴다.
     임계값을 넘겼다고 탐색을 멈추지 않는다(그 자체가 누수다).
4. 서빙은 `ml/inference/` 래퍼를 통해 backend `/api/v1/ai/*`와 연동.
5. 거점 데이터 순서: 신사동 가로수길 → 성수동.
