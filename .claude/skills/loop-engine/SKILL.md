# 루프 엔진 — 상태를 읽고 다음 한 수를 고른다

`hub-chain` 이 **정해진 순서를 내려가는 것**이라면, 이것은 **지금 상태에서 무엇을 할지
고르는 것**이다. 거점·트랙·게이트가 뒤섞인 채 진행될 때 쓴다.

## 한 사이클 (6단계)

### ① 상태를 읽는다 — 문서가 아니라 산출물에서

```bash
python scripts/pppp_status.py                  # 트랙별 진행률 + 게이트
python scripts/chain_status.py --all --next    # 거점별 다음 한 수
python scripts/quota_preflight.py              # 오늘 쿼터가 열렸는가
```

세 개 다 **읽기 전용**이고 네트워크를 안 탄다(쿼터 프로브 1콜 제외).
`[선언]` 게이트는 근거 경로를 열어 **여전히 참인지 확인한 뒤에만** 인용한다.

### ② 막힌 것을 세 종류로 가른다

| 종류 | 뜻 | 이번 사이클에서 |
|---|---|---|
| **안 정했다** | 제품 판단이 없다 | **최우선** — 지금 정하면 풀린다 |
| **못 얻는다** | 자료·승인·채널이 없다 | 신청·결정을 넣어두고 **다른 것을 병행** |
| **시간만 필요** | 쿼터·학습시간 | 걸어두고(`autorun`) 잊는다 |

셋을 "미착수"로 뭉뚱그리면 착수만 하면 되는 것처럼 읽힌다.

### ③ 한 수를 고른다 — 라우팅

| 상태에서 읽힌 것 | 부를 skill |
|---|---|
| 거점 단계가 `점포`/`폴리곤`/`대장`에서 멈춤 | `hub-chain` (해당 거점) |
| 쿼터가 열려 있고 대장 잔여 있음 | `quota` → 길면 `autorun` |
| Gold 는 있는데 API 가 비어 있음 | `gold-build` |
| Page/Platform/Posting/Program 게이트가 낮음 | 해당 트랙 skill |
| 화면·토큰·정보구조 문제 | `design` (구현은 `frontend-dev`) |
| "되는가"를 모름 | `probe-first` — **추측으로 코드를 짜지 않는다** |
| 명세가 확정된 단순 실행 | `codex-handoff` |
| 변경분이 쌓임 | `verify` → 통과 시 `deploy` |
| 여러 트랙에 걸친 큰 목표 | `director` |

**쿼터가 닫혔으면 수집을 고르지 않는다.** 하루치가 사라지는 자원이라 열렸을 때만 태우고,
닫힌 동안은 판단·화면·문서 작업으로 넘어간다.

### ④ 두고 나서 산출물로 확인한다

한 수를 둔 뒤 ①의 프로버를 **다시** 돌린다. 진행은 "했다"가 아니라 **수가 바뀌었다**로
확인한다. 안 바뀌었으면 그 수는 진행이 아니었다.

### ⑤ 기록한다

- 값이 바뀐 판단 → `docs/finding-*.md` (날짜를 파일명에)
- 절차가 바뀌었으면 → 해당 **skill 을 고친다**. 이 루프의 산출물에는 skill 자체도 포함된다.
- 게이트 구성이 바뀌면 → `scripts/pppp_status.py` 의 `*_track()`, `scripts/chain_status.py` 의 단계

### ⑥ 다음 사이클

정지 조건에 걸리지 않으면 ①로 돌아간다.

## 정지 조건 — 이게 없으면 루프가 아니라 헛돎이다

1. **같은 단계가 두 사이클 연속 안 움직였다** → 멈추고 사람에게 묻는다.
   같은 명령을 세 번째 돌리지 않는다.
2. **되돌리기 어려운 문턱** — 서빙 등재(`seoul_pages.DISTRICTS`), 프로덕션 배포,
   기존 Gold 덮어쓰기, `--force` 재수집. 루프가 스스로 넘지 않는다.
3. **판단이 필요한 갈림길** — 거점 채택/기각, 앵커 공유 표기 여부, 모델 pooled 분리.
   후보와 근거를 정리해 두고 멈춘다.
4. **쿼터·전원·자원 소진** → `autorun` 규칙으로 걸어두고 사이클을 닫는다.
5. **가드레일 위반**(앵커 격차 30%p 초과, CI 빨강) → 원인 규명 전 다음 단계 금지.

## 자동 반복으로 돌릴 때

`/loop` 로 이 skill 을 주기 실행할 수 있다. 그때는 사이클마다:

- 바뀐 것이 없으면 **아무것도 하지 않았다고 보고한다**(없는 진행을 지어내지 않는다).
- 무인 실행은 **고치지 않고 기록만 한다** — 자리에 없는 사이에 자동으로 고치기 시작하면
  무엇이 왜 바뀌었는지 아무도 모른다(`autorun` §4).
- 사이클 로그는 `reports/` 에 남긴다.

## 첫 사이클 예시 (2026-08-30 실측)

```
① chain_status --all --next → hwajeong·geumchon·unjeong·ilsan 이 '점포' 단계
② 분류: '시간만 필요'(수집) — 안 정한 것은 rone-shared 표기 하나
③ 라우팅: hub-chain(hwajeong) + 병행으로 rone_districts 매핑 판단
④ 수집 후 chain_status 재실행으로 '점포' → ok 확인
⑤ 건물당 점포 비율을 finding 에 기록
```
